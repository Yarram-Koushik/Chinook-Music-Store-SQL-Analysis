# Chinook Music Store - SQL Analysis

## Project Overview
A comprehensive SQL analysis of the Chinook Music Store database, exploring business insights through structured queries covering sales performance, customer behavior, genre trends, and more.

## Repository Structure

```
├── Documentation/
│   └── KoushikYarram_Chinook_Answers.docx    # Detailed answers with screenshots
├── Presentation/
│   └── KoushikYarram_Chinook_Presentation.pptx  # Summary presentation
├── SQL/
│   ├── Chinook_Music_Store_DB.sql             # Database schema & data
│   └── KoushikYarram_Chinook_SQL.sql          # Analysis queries
└── README.md
```

## Key Analysis Areas
- **Sales Analysis** – Revenue trends, top-selling tracks, and artist performance
- **Customer Insights** – Spending patterns and geographic distribution
- **Genre & Media Analysis** – Popular genres and media type preferences
- **Employee Performance** – Support agent effectiveness

## Tools Used
- **Database**: SQLite / MySQL
- **SQL**: Complex queries with JOINs, subqueries, CTEs, window functions, and aggregations
